# INEMA Agent Runtime — faça qualquer IA usar qualquer ferramenta

Curso gratuito do [INEMA.CLUB](https://inema.club) que ensina a usar o kit [inema-agent-runtime](https://github.com/inematds/inema-agent-runtime): fazer o Claude Code e o Codex descobrirem, conectarem e usarem as ferramentas que você já tem, pela via mais estável que existir e com regras claras do que podem fazer sozinhos. Tudo pela assinatura, sem API paga.

**Abrir o curso:** https://inematds.github.io/curso-agent-runtime/ · [English](https://inematds.github.io/curso-agent-runtime/en/) · [Español](https://inematds.github.io/curso-agent-runtime/es/)

| Trilha | Módulos |
|---|---|
| 1 · Descobrir | Engenharia reversa não é produto · Instalar e diagnosticar · A escada das vias · O mapa de capacidades |
| 2 · Conectar | Claude usa o Codex · Sua primeira ponte MCP · A ponte do seu sistema · Navegador com política |
| 3 · Rotear e executar | Modelo certo, cota rende · Time de três papéis · Time em segundo plano · Agente longo com verificação |
| 4 · Governar e aprender | Política de autonomia · O agente propõe, você aprova · Guarda e painel · Laboratório e projeto final |

Projeto final: **sua ponte e seu time** — um sistema sem API do seu trabalho, conectado pela via mais alta possível, com um time de três papéis e prova pelo `verificar.mjs`.

Formato `formato-curso-v2` (HTML + Tailwind CDN + JS, sem build). Progresso, dúvidas e notas ficam só no navegador.

Manutenção: edite `context/corpos/`, rode `python3 scripts/montar.py` e `python3 scripts/lint.py`.
