A ideia que atravessa o curso

Engenharia reversa não é produto, é técnica de descoberta.

Vídeos sobre "mods" do Claude Code mostraram o Claude usando o Codex e várias sessões trabalhando em paralelo, quase tudo por engenharia reversa. A ideia é ótima; o caminho quebra na próxima atualização. Hoje quase tudo aquilo tem via oficial: codex exec, claude --bg e claude agents, plugins oficiais do Claude Code.

Regra do kit: suba a escada e use sempre a via mais estável que existir — API → MCP → CLI → SDK → uso do computador → ponte local → engenharia reversa (só laboratório).
