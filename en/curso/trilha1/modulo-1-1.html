See what the mod videos showed

Videos showing Claude Code “mods” circulated. In one of them, Claude started using the computer use of the Codex app: you clicked, typed, and read the screen through another AI.

In another, several Claude sessions worked at the same time, each in a different role, with a dashboard showing who was leading and who had stalled. The nickname was "Threads".

Almost everything was done by reverse engineering: look at the running application, find out how it communicates internally, and connect a wire there, without an invitation from the manufacturer.

🆕 New here? Five words that come up all the time

  • Claude Code — Claude running in your machine's terminal. It reads and creates files and runs commands in the folder where you open it.
  • Codex — OpenAI's equivalent tool, also in the terminal. The command codex exec sends a request and gets the response without opening the screen.
  • Agent — an AI equipped with tools that acts on its own: creates files, runs commands, opens websites.
  • Mod (plugin) — a package that adds things to Claude Code: a panel, a new command, a rule that runs before each action.
  • Reverse engineering — figuring out how a program works internally by observing it, without official documentation.

How to read the diagram: The blue section is what the manufacturer provides (the app using the computer). The red dashed section is the improvised connection someone built to access it. That connection disappears when the app updates.

2

Separate product discovery

Reverse engineering has value. It proves that something is possible, shows how the program communicates and shuts down the premature "it can’t be done."

The problem starts when the discovery becomes part of your daily system. Then you depend on something the manufacturer could change tomorrow without notice. The rule for this course fits on one line: reverse engineering is a discovery technique, not a product.

✓ As a discovery tool (works)

  • ✓ Shows the idea works before you invest
  • ✓ Shows what data the program exchanges and where it goes
  • ✓ Prompts the right question: “Is there an official way to do this?”
  • ✓ Runs on a test machine, with the date recorded

✗ As a product (doesn’t work)

  • ✗ Breaks with every app update
  • ✗ No one guarantees that the behavior stays the same
  • ✗ May violate the provider’s terms of use
  • ✗ You become the only one who knows how to fix it

How to read the diagram: reverse engineering appears only in the first frame. What determines the path is the green box in the middle. In most cases in 2026, the answer is "yes," and your system follows the blue arrow.

💡 Phrase to remember

When someone shows you an impressive trick, ask: "is this the way, or proof that a way exists?". Almost always, it's the latter.

🆕 New here? What are "official route" and "CLI"

Official method it’s the route the manufacturer provides for other programs to communicate with its system, and that it commits to maintaining. CLI (command-line interface) is a program you use by typing commands in the terminal, such as claude, codex or git.

Understand what the kit is

O INEMA Agent Runtime is a kit you copy into your project. It helps Claude Code and Codex discover, connect to, and use the tools you already have, with clear rules about what they can do on their own.

It's not a platform or a server. It's a folder runtime/ with four rules files, diagnostic and verification scripts, bridges, a guard, and seven tested recipes. It works through the subscription for Claude Code and/or Codex.

🆕 New here? A subscription isn't an API

A subscription is the monthly plan you already pay for to use Claude or ChatGPT. It has a quota: a usage limit per period. A API is another account, billed based on usage and designed for programmers. The kit runs only through the subscription: no paid API is required.

Go through the seven-step cycle

The file runtime/LEIA-ME.md organize everything into a cycle: discover → connect → route → execute → observe → verify → learn. Each step has a file and a question.

And every action, at every stage, goes through the POLITICA.md: it says what the agent does on its own and what it asks first.

How to read the diagram: The dashed ring shows the order of the steps, and "learn" (green) sends the cycle back to the beginning with better rules. The lines to the center show that no step escapes the policy.

💡 What counts as “proof” in the kit

Every recipe ends with a Proof: a command and the text that must appear. Example from recipe R1: run the bridge with "Reply only PONG" and see PONG. If it doesn't appear, it didn't work, even if the agent says it did.

🆕 New here? ERP and CSV

ERP is the company management system (sales, inventory, invoices). CSV is a plain-text spreadsheet: each line is a record, and the columns are separated by commas. Almost every legacy system can "export CSV," and that's enough for the agent to read it.
